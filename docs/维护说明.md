# 例程维护说明

## 目录约定

每个例程放在 `examples/<芯片或场景名称>/`，包含完整工程、中文 README、产品配置及必要的测试数据点。公共工具放在 `tools/`，通用说明放在 `docs/`。

首个例程来自内部固件仓库的 `templates/soc_basic` 验证基线，已复制为独立源码，不通过相对路径依赖内部仓库。内部 SDK 验证入口位于 `boards/sdk`，实际 SoC 产品位于 `boards/soc`。

## 新增例程

复制相近例程，修改产品与硬件配置，并补齐自己的中文接入和验收步骤。不要在各例程中复制 SDK 内部联网、鉴权或协议路由实现。源码注释重点说明生命周期、线程要求、回调参数和客户需要修改的位置。

## 更新 SDK

1. 从内部 SDK 导出流程取得完整包和构建验证记录。
2. 核对芯片、云平台、BLE 协议、Hosted 接线、摄像头能力/参数/后端配置和工具链要求。
3. 更新根目录 `sdk.lock.json` 的清单哈希及对应元信息，不手改某一个 `.a`。
4. 在干净工作目录安装 SDK、构建全部受影响例程，再按上板验收说明测试。
5. 提交例程、说明和锁定文件；SDK 包作为独立版本化交付物分发。

安装脚本拒绝清单或文件哈希不一致的 SDK；已安装相同版本可重复执行。升级时在新工作目录验证，避免覆盖客户正在使用的 SDK。

## 本地版本管理

仓库使用 `main` 分支，未设置远端。准备好自己的远端仓库后再执行：

```sh
git remote add origin <你的仓库地址>
git push -u origin main
```

SDK 安装目录、构建缓存、个人编辑器配置及本地 `product_secrets.hpp` 已加入忽略规则。示例内置的凭据仅属于获准公开的测试产品。

首个例程使用内部 `boards/sdk/p4_sdk_camera` 导出的包（无识别模型）。`p4_sdk_basic` 继续用于无摄像头项目。SDK 将实际构建的媒体依赖固定为本地组件，可在关闭 Component Manager 后构建；不能只从包里挑选单个库替换。
