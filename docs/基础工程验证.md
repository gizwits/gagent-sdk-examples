## 自动化验证

```sh
python3 tools/install_sdk.py --verify-only
python3 -m unittest discover -s tests -p 'test_basic_projects.py' -v
cmake -S tests -B /tmp/gagent-example-tests
cmake --build /tmp/gagent-example-tests
ctest --test-dir /tmp/gagent-example-tests --output-on-failure
```

基础工程测试覆盖离线生成、业务回调保留、协议与回调的 C++17 编译、更换 PK 后拒绝旧数据点、缺少配置时的提示、统一分区和 SDK 哈希。

生产仓库运行 `test_product_setup.py`、`test_board.py`、`test_sdk.py`、`test_soc_generator.py`，共 51 项测试。覆盖请求不发送 PS、错误输入不覆盖旧文件、缓存生成、目录替换失败回滚、拒绝缩小分区，以及协议生成回归。

本次默认样例为 `standard` 协议的 4 个字段：`power`、`using_led_light`、`power_memory`、`timer_s`。样例重建和重新导出都有自动化验证，覆盖离线复现、不同产品拒绝使用样例以及样例完整性检查。真实凭据和实际生成目录留在本地忽略路径；公开仓库只包含空白凭据模板和脱敏样例。
