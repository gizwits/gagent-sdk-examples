# C2 开发者工程发布验证

新增 `examples/c2_iot_basic`，包含 ESP32-C2 二进制 SDK、默认产品 4 个数据点的脱敏样例，以及生成和重建说明。实际 PK/PS 与 `main/generated/` 仅存于本地忽略路径。

- 硬件配置：4MB Flash、26MHz 晶振、最低修订版 v2.0。
- 配网：BLE V2，保留 C2 专用内存配置，关闭 SoftAP。
- 控制台：标准 UART0，TX GPIO20 / RX GPIO19，74880 波特率。
- 分区表：与 C3/C5 及生产仓库现有 4MB 基线逐字节相同。

使用锁定的 ESP-IDF 6.1（`2f8327156dd1f3c010413a6d47c9f86a607be498`）和 GCC 15.2.0，完成生产端 SDK 构建及独立例程完整编译/链接。独立例程使用本地默认产品凭据，通过 `configure_product.py --sample` 重建 4 个数据点；验证没有编译内部 SDK 实现源码。

固件大小 **1342096 字节**（`0x147a90`），OTA 槽 `0x1d0000`，剩余 `0x88570`（约 29%）。SDK 完整性、目标芯片、配置一致性及分区容量检查通过。

生产端 51 项 Python 测试通过；例程仓库 3 个 CTest 测试组通过，其中基础工程的 4 项 Python 测试覆盖 C2/C3/C5。四套 SDK（C2/C3/C5/P4）的哈希校验通过。此次未更改 C3/C5/P4 SDK，其完整构建记录见[首次发布验证](发布验证.md)。

尚未进行实机烧录、BLE 配网、云端收发或 OTA 验收。镜像及 SDK 哈希见[机器可读记录](C2发布验证.json)。
