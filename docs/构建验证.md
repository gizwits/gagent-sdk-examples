# 构建验证记录

2026-11-09 使用 `sdk.lock.json` 锁定的 SDK、ESP-IDF 和工具链完成独立构建。SDK 由 `new-gagent` P4 分支的正式 `tools/package_sdk.py` 产出，只注册 6 个 GAgent 组件；核心 GAgent 静态库与此前验证版本逐字节相同，没有重新编译业务库。

SDK 文件合计约 25.6 MiB，原完整包约 589 MiB。mDNS 1.12.0 与其余 Registry 组件由样例 `main/idf_component.yml` 声明精确版本，`dependencies.lock` 固定组件内容。摄像头需要的定制 WebRTC、Peer、渲染和平台抽象库归入 `gagent_camera/support/`，保留许可证和必要 Kconfig，不增加独立源码组件。摄像头包要求 CMake 3.24 或更新版本，导入脚本为 ESP-IDF 的 Generic 工具链定义静态库分组，解决内部循环引用。

验证从隔离的空工程开始，下载并编译锁定的第三方组件、链接应用，最后在未设置 `IDF_COMPONENT_MANAGER` 的环境中执行默认 `idf.py build`，输出 `Project build complete`。无需内部固件仓库的实现源码。SDK 文件哈希、配置一致性和 OTA 槽容量检查通过；应用镜像为 3,598,032 字节，每个 OTA 槽为 7,340,032 字节。

源码指纹、例程 Git 子树、导出脚本提交号、SDK 清单和最终镜像 SHA-256 见 [构建验证.json](构建验证.json)。记录中的例程文件与实际消费工程逐个比对一致；客户修改后应重新构建和验收。

SDK 导出器的 9 项测试通过，覆盖 Registry 依赖分类、mDNS 版本声明、摄像头内部配套库、许可证和 Kconfig、独立例程隔离及 SDK 兼容检查。例程的 2 项主机 UI/外设测试通过。应用业务源码未改动。

本次未烧录或进行新的硬件验收。此前版本已在 P4 v3.2 测试板确认启动、按键/LED 驱动初始化和 MQTT 联网，用户反馈按键可用。实际灯效、视频与异常场景仍按 [上板验收](上板验收.md) 检查。
